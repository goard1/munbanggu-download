# 추억의 문방구 — 테스트 APK

할머니가 남긴 골목 문방구를 다시 여는 안드로이드 게임의 **테스트 버전**입니다.

## ⬇ 받기
**[최신 테스트 버전 받기 (Releases → Latest)](https://github.com/goard1/munbanggu-download/releases/latest)** → `munbanggu-test.apk`

## 설치 전에 확인
| | |
|---|---|
| 안드로이드 | **8.0 이상** |
| 폰 종류 | **ARM64 (64비트)** — 요즘 나온 폰은 대부분 해당. x86 에뮬레이터(일부 PC 앱플레이어)에선 실행되지 않을 수 있어요 |
| 처음 설치 | 받은 파일을 누르면 「출처를 알 수 없는 앱 설치 허용」을 켜 달라고 나와요 |
| 업데이트 | 새 버전을 그대로 덮어 설치하면 저장이 이어져요 (지우고 다시 깔면 저장도 지워져요) |
| 언어 | 한국어 · 繁體中文 · English (타이틀 화면에서 선택) |

테스트 버전이라 설정 창에 시험용 버튼(돈·평판·날짜)이 있어요.

## 🐞 버그·의견 제보
**[제보하기 (Issues → New issue)](https://github.com/goard1/munbanggu-download/issues/new/choose)** — GitHub 계정이 필요해요.

이것만 적어 주면 고치기가 훨씬 쉬워요:
1. **버전 줄** — 타이틀 화면 맨 아래 작은 글씨 (예: `v0.2.0 · 09a878f · 2026-11-22`)
2. 폰 기종 · 안드로이드 버전
3. 게임 언어
4. 슬롯 번호 · 게임 날짜(n일차) · 아침/영업 중/정산 중 언제였는지
5. 바로 전에 한 행동, 그리고 스크린샷
